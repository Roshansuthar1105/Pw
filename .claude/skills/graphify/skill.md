graphify transforms any folder of files (code, docs, papers, images) into a navigable knowledge graph with community detection. It creates three outputs: interactive HTML visualization, GraphRAG-ready JSON, and a plain-language audit report. Key features include persistent storage (survives sessions), honest edge tagging (EXTRACTED/INFERRED/AMBIGUOUS), and cross-document surprise detection via community analysis. Usage: `/graphify [path]` processes the directory, with flags for deep extraction, updates, visualization formats, and querying. The tool prioritizes transparency—showing exactly what was found versus inferred—and enables exploration of non-obvious connections across disparate files. Outputs land in a hidden `graphify-out/` folder containing the graph, report, and visualization assets.
